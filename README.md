# Portfolio

A personal portfolio website for Sadhana Sainarayanan showcasing cloud security, platform engineering, AI agent accountability, and MLOps expertise.

## Overview

This repository contains a lightweight static portfolio page built with a single `index.html` file. It is designed to present experience, projects, skills, education, and contact information in a polished, responsive layout.

## What’s included

- `index.html` — the complete portfolio page with inline CSS and JavaScript
- responsive navigation, hero section, skills, projects, experience, education, and contact sections
- typewriter animation for the hero tagline
- dark theme with modern tech-style visuals

## Technologies

- HTML5
- CSS3
- JavaScript

## Local preview

Open `index.html` directly in a browser, or run a local HTTP server for the best experience:

```bash
cd /workspaces/Portfolio
python3 -m http.server 8000
```

Then open `http://localhost:8000` in your browser.

## Customize

Edit `index.html` to update:

- text and section content
- contact links
- project cards and skills
- colors and layout in the inline stylesheet

## Notes

This repository is a static portfolio site and does not require a build step or external dependencies.
